タイムラインの設定

360°モードでは、指の向きのとおりに横（時間）と縦（段）が同時に動きます。どちらのモードでも Shift+ホイールで縦横が入れ替わり、Ctrl（⌘）+ホイールやピンチで拡大縮小、左の見出し列の上では縦にスクロールします。
自動判別がうまく合わないときは「常に360°」か「マウスホイールと同じ扱い」に切り替えてください。

直前のスクロール: —
コメントプリセット

よく使うコメントを好きなだけ登録できます。ボタンを押すと再生位置にすぐ投稿されます（Shift+クリックで入力欄に挿入）。コマンドを空にすると入力欄のコマンドが使われます。先頭から10個はキーボードの 1〜9, 0 でも投稿できます。
ほかの人の変更と重なった変更

同じコメントを同時に変えたため、変更はまだ反映されていません（今はホストにある内容になっています）。「元の値」は変更を始めたときの内容です。コメントごとにどうするか選んでください。
「あとで」にすると、ほかの参加者の一覧にも出て、誰でも選べるようになります。
プロジェクト

「開く」はこのタブのまま切り替えます（動画・再生位置・タイムラインの表示はプロジェクトごとに覚えていて、戻ってくると元に戻します）。「新しいタブ」なら、ほかのプロジェクトや同じプロジェクトを並べて作業できます。
ログイン

このホストに入るには、ホストの人から受け取ったワンタイムパスワードを入れてください（1回だけ使えます。一度入れば、このブラウザでは次から入れ直す必要はありません）。
招待・ログインの管理
共同編集の参加者

ほかの人の再生位置・選んでいるコメント・マウスカーソルは、その人の色でシークバーやタイムラインに出ます。
「追いかける」を押すと、その人の再生位置とタイムラインの表示に合わせ続けます（自分で操作するとやめます）。
使い方

基本の流れ（複数人で作る場合）

  1. 全員が同じ動画ファイルを手元に用意し、「動画を開く」で読み込む
  2. コメントファイル（.json）を開く。最初の人は新規のままでOK
  3. コメントを書き込み、「保存」でファイルに書き出す（開いたファイルへ追記されます）
  4. ファイルを共有し、受け取った側は「マージ」で自分のコメントと統合

マージは「時刻・コマンド・本文」が完全に同じものを重複とみなす和集合です。同じ順序規則で並べ直すので、マージ後は誰の環境でもほぼ同じ配置で流れます（フォントの違いで多少ずれることはあります）。Chrome / Edge では開いたファイルに直接上書き保存でき、保存のたびにファイル側の新しいコメントも取り込みます（Dropbox などの共有フォルダ上のファイルを複数人で開いても失われにくくなっています）。

コメントプリセット

入力欄の下の「＋ プリセットを登録」（登録後は「⚙ 編集」）から、よく使うコメント（888 など）を好きなだけ登録できます。ボタンを押すと再生位置にすぐ投稿、Shift+クリックで入力欄に挿入。先頭10個はキー 1〜9, 0 でも投稿できます。

書き出し

「高速」は動画ファイルを直接デコード・エンコードするので再生より速く、処理中も編集やタブの切り替えができます（「バックグラウンドで続行」でダイアログを閉じても続きます）。形式は MP4 / MOV / WebM / MKV。対応していない環境や動画では「リアルタイム録画」を使ってください。

Vim エディタ

コメントを1行1件のテキスト（01:23.45 ue red | 本文）として Vim のキー操作で編集できます。時刻やコマンドを書き換えて :w で反映、:q で閉じます。:now で再生位置に行を追加、:seek でカーソル行の時刻へ移動。対応キーの一覧はエディタ内で :help。スマホでは画面下のキーバーで Esc や Ctrl を入力できます（Esc は上の :w の隣にもあります）。

変更履歴

右の「変更履歴」タブで、コメントの追加・変更・削除を新しい順に見られます。「取り消す」でその変更を打ち消す変更を加え（その後に同じコメントが変わっていれば止まります）、「移動」でそのコメントの時刻へ移ります。共同編集中は全員の変更が出ます。

みんなで編集する

komenagare コマンドでホストしたページを開くと、ほかの参加者と同じコメントを同時に編集できます（右上に「共同編集」と表示されます）。変更はホストのフォルダに保存され、git の履歴に残ります。同じコメントの同じ項目を同時に変えたときは先に届いた方が残り、「⚠ 衝突」から自分の変更にする・相手のままにする・両方残すを選べます。「あとで」にした衝突はほかの参加者にも出て、誰でも選べます。接続が切れても編集を続けられ、つながり直したときに送られます。

ホストが複数のプロジェクトを共有しているときは、右上の「📁」からプロジェクトを切り替えたり、新しいタブで開いたりできます（同じプロジェクトを複数のタブで開いてもかまいません）。ホストがワンタイムパスワードを使っているときは、最初に受け取ったワンタイムパスワードでログインします。

ローカルネットワークの外から使うときは、ホストを komenagare --otp --tunnel tailscale（または cloudflare / ngrok）で起動するか、自分で用意した URL を --public-url で渡します。詳しくは README を見てください。

ほかの参加者の再生位置・選んでいるコメント・マウスカーソルは、その人の色でシークバー・タイムライン・リスト・プレビューに薄く出ます。右上の「共同編集」を押すと参加者の一覧が開き、表示名の変更や、選んだ人の再生位置とタイムラインの表示を「追いかける」ことができます（自分でシークやスクロールをするとやめます）。

ファイル形式

JSON：{"t": 秒, "cmd": "コマンド", "text": "本文", "id": "UUID"} の配列（comments キー内）。CSV：time,command,text,id の4列。id は各コメントを見分ける番号で、省略すると読み込み時に新しく付きます。読み込みはニコニコのコメントXML（<chat vpos mail>）やコメントJSONにも対応しています。
