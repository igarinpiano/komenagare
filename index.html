言語
コメントプリセット

よく使うコメントを好きなだけ登録できます。ボタンを押すと再生位置にすぐ投稿されます（Shift+クリックで入力欄に挿入）。コマンドを空にすると入力欄のコマンドが使われます。キーの欄を押してからキーを押すと、そのキーでも投稿できます（Backspace で外す。Space・矢印・K・C・F・M・I・O など、ほかの操作に使っているキーと、Ctrl・⌘・Alt との組み合わせは使えません）。
ほかの人の変更と重なった変更

同じコメントを同時に変えたため、変更はまだ反映されていません（今はホストにある内容になっています）。「元の値」は変更を始めたときの内容です。コメントごとにどうするか選んでください。
「あとで」にすると、ほかの参加者の一覧にも出て、誰でも選べるようになります。
プロジェクト

「作る」はまとめフォルダに新しいフォルダを作ります。「外す」はこのホストでの共有をやめて、まとめフォルダのリポジトリからも外します（それまでの履歴には残り、ホストのフォルダとコメントもそのまま。「プロジェクトを復元」で戻せます。開いている人は切断されます）。

「開く」はこのタブのまま切り替えます（動画・再生位置・タイムラインの表示はプロジェクトごとに覚えていて、戻ってくると元に戻します）。「新しいタブ」なら、ほかのプロジェクトや同じプロジェクトを並べて作業できます。
プロジェクトを復元

外したプロジェクトです。選んで「復元」すると、同じ id（共有のリンクもそのまま）で戻り、まとめフォルダのリポジトリにも戻ります。ホストに無いもの（別の場所で外したもの）は、外す前の履歴から取り出します。
ログイン

このホストに入るには、ホストの人から受け取ったワンタイムパスワードを入れてください（1回だけ使えます。一度入れば、このブラウザでは次から入れ直す必要はありません）。
招待・ログインの管理
共同編集の参加者

ほかの人の再生位置・選んでいるコメント・マウスカーソルは、その人の色でシークバーやタイムラインに出ます。
「追いかける」を押すと、その人の再生位置とタイムラインの表示に合わせ続けます（自分で操作するとやめます）。
この時点に復元


履歴を巻き戻す（git reset）のではなく、今の状態からこの時点の状態に戻す変更を、新しいコミットとして記録します。参加者全員に届き、それまでの履歴もそのまま残るので、あとでまたタイムマシンで戻せます。

使い方

  

    
基本の流れ（複数人で作る場合）

    
    
      
  1. 全員が同じ動画ファイルを手元に用意し、「動画を開く」で読み込む
    2. 
      
  2. コメントファイル（.json）を開く。最初の人は新規のままでOK
    3. 
      
  3. コメントを書き込み、「保存」でファイルに書き出す（開いたファイルへ追記されます）
    4. 
      
  4. ファイルを共有し、受け取った側は「マージ」で自分のコメントと統合
    5. 
    

    
マージは「時刻・コマンド・本文」が完全に同じものを重複とみなす和集合です。同じ順序規則で並べ直すので、マージ後は誰の環境でもほぼ同じ配置で流れます（フォントの違いで多少ずれることはあります）。Chrome / Edge では開いたファイルに直接上書き保存でき、保存のたびにファイル側の新しいコメントも取り込みます（Dropbox などの共有フォルダ上のファイルを複数人で開いても失われにくくなっています）。


    
コマンド（ニコニコ動画準拠）

    

      
位置naka（流れる・既定） ue（上固定） shita（下固定）

      
サイズbig medium（既定） small

      
色white red pink orange yellow green cyan blue purple black

        プレミアム色 white2 red2 … black2（niconicowhite truered 等の別名も可）、カラーコード #RRGGBB

      
フォントdefont（既定） gothic mincho

      
表示時間@秒数（例 @10）

      
その他invisible（非表示） full（上下コメの縮小幅を画面全体に） ender（改行リサイズ無効） _live（半透明）

    

    
同じ種類のコマンドが複数ある場合は先に書いたものが優先されます。改行の多いコメントは自動で縮小され（big 3行・medium 5行・small 7行以上）、上下固定で画面からはみ出すものは幅に合わせて縮小されます。表示しきれないコメントはランダムな高さに重なって表示されます。

画面の配置

    
PC では、メニューバーの右の「配置」から、パネルの並べ方を選べます。「標準」（上にプレビューとリスト、下にタイムライン）、「右にリスト」（左にプレビューとタイムライン、右にリストを縦いっぱい）、「右にタイムライン」（左にプレビューとリスト、右にタイムラインを縦いっぱい）の3つです。隣の3つのボタン（プレビュー・リスト・タイムライン）でパネルを出したり隠したりでき、タイムラインだけ・プレビューとリストだけのようにもできます。パネルの間のすき間をドラッグすると大きさが変わり（ダブルクリックで元の大きさ）、配置ごとに覚えています。プレビューの枠が低くなると、プリセットのボタンがコメント欄の右に並び、動画をなるべく大きく残します。スマホでは下のタブで切り替えます。


    
タイムライン

    

      
全体表示（細い帯）黄色い枠をドラッグで表示位置を移動、枠の左右端をドラッグで拡大縮小。枠の外をタップするとそこへジャンプ

      
コメントの移動コメントをドラッグ（スマホは一度タップして選択してからドラッグ）

      
複数選択⌘（Windows・Linux は Ctrl）＋クリックで1つずつ足したり外したり、⌘＋ドラッグで範囲を囲んでまとめて足します（⌘ を押すとカーソルが十字になります）。「⬚ 範囲選択」をオンにすると、空いている所のドラッグで囲めます（スマホ向け）。選んだものはまとめてドラッグで移動、Delete で削除、, . でずらせます

      
複製Option（Alt）＋コメントをドラッグすると、選んでいるコメントを複製してドラッグした所に置きます（元はそのまま。Option を押すとコメントの上でカーソルが「＋」になります）

      
長さを決めて作成Shift＋空いている所を横にドラッグすると、その範囲に見えるコメントをその段（上・流・下）に作ります（表示時間はドラッグした長さ。流れるコメントは 1 秒前から見えるので、その分を差し引きます）

      
開始・終了の調整選択したコメントの左端／右端をドラッグ。表示時間が変わり、流れるコメントはその分速さが変わります（@秒数 が自動で付きます）

      
作成・本文の変更「＋ 新規」、空いている所をダブルクリック（ダブルタップ）で作成。コメントをダブルクリックか Enter で本文や時刻を編集

      
拡大縮小・移動Ctrl+ホイール・ピンチ・＋／− で拡大縮小、ホイール・空き部分のドラッグで移動。上下は右のスクロールバー、Shift+ホイール、左の見出し列でのホイールで。ホイールの向きは ⚙ で変更でき、トラックパッドや Magic Mouse では360°自由に動かせます。目盛りか再生位置の赤い線をドラッグで再生位置（そのときの時刻はマウスの横に出ます）

      
高さタイムラインとほかのパネルの間のすき間をドラッグ（ダブルクリックでリセット）。2本のすき間が交わる所をドラッグすると、高さと幅を同時に変えられます。縦向きのスマホでは「タイムライン／リスト／Vim／履歴」のタブの上のつまみをドラッグすると動画の大きさが変わり、残りが下の画面になります。段の高さは右端の設定（低い・ふつう・高い）で変えられます

      
タイムコード左上の数字は再生位置です。押して時刻（1:23.5 など）を打ち、Enter でそこへ移ります。横の ▶ で再生・一時停止（プレビューを隠していても使えます）。マウスを重ねると、その位置に細い線と時刻が出ます

      
イン点・アウト点「[→」「→]」（キー I O）で再生位置を範囲の始まりと終わりにします。範囲は目盛りとシークバーに琥珀色で出て、書き出しの範囲の初期値になります。「↻」のループ再生をオンにすると、範囲（無ければ全体）をくり返し再生します。「×」で範囲を消します

      
追従「追従」がオンのとき、再生位置が中央まで来るとそこで止まり、タイムラインの方が流れます

      
キー（タイムライン選択中）Delete 削除　Enter 編集　, . 0.1秒ずらす（Shift で1秒）　N スナップ　Shift+Z 全体

    


    
コメントプリセット

    
入力欄の下の「＋ プリセットを登録」（登録後は「⚙ 編集」）から、よく使うコメント（888 など）を好きなだけ登録できます。ボタンを押すと再生位置にすぐ投稿、Shift+クリックで入力欄に挿入。プリセットごとに好きなキー（英字・数字・記号・F1 など。Shift との組み合わせも）を割り当てると、そのキーでも投稿できます（最初は 1〜9, 0 が順に付きます）。


    
書き出し

    
「高速」は動画ファイルを直接デコード・エンコードするので再生より速く、処理中も編集やタブの切り替えができます（「バックグラウンドで続行」でダイアログを閉じても続きます）。形式は MP4 / MOV / WebM / MKV。対応していない環境や動画では「リアルタイム録画」を使ってください。解像度は元動画と同じ大きさ（8K なども）か、それより小さい大きさを選べます。ビットレートは「元動画と同じ」（既定）・「解像度に合わせる」・数値から選べます。Chrome / Edge などでは書き出し開始で保存先を選び、そこへ少しずつ書き込むので、長い動画もメモリをあまり使いません。保存先を選べないブラウザではダウンロードで保存し、一度に書き出せるのは 4 GB までです。8K のような大きな動画は、CLI の komenagare render で書き出すのがおすすめです。


    
Vim エディタ

    
コメントを1行1件のテキスト（01:23.45 ue red | 本文）として Vim のキー操作で編集できます。時刻やコマンドを書き換えて :w で反映、:q で閉じます。:now で再生位置に行を追加、:seek でカーソル行の時刻へ移動。長い行は折り返して表示します。:set nowrap で折り返さない（横にスクロール）、:set linebreak で単語の区切りで折り返します（:set で変えた設定は次に開いたときも使われます）。対応キーの一覧はエディタ内で :help。スマホでは画面下のキーバーで Esc や Ctrl を入力できます（Esc は上の :w の隣にもあります）。


    
変更履歴

    
右の「変更履歴」タブで、コメントの追加・変更・削除を新しい順に見られます。「取り消す」でその変更を打ち消す変更を加え（その後に同じコメントが変わっていれば止まります）、「移動」でそのコメントの時刻へ移ります。共同編集中は全員の変更が出ます。


    
みんなで編集する

    
komenagare コマンドでホストしたページを開くと、ほかの参加者と同じコメントを同時に編集できます（右上に「共同編集」と表示されます）。変更はホストのフォルダに保存され、git の履歴に残ります。同じコメントの同じ項目を同時に変えたときは先に届いた方が残り、「⚠ 衝突」から自分の変更にする・相手のままにする・両方残すを選べます。「あとで」にした衝突はほかの参加者にも出て、誰でも選べます。接続が切れても編集を続けられ、つながり直したときに送られます。

    
ホストが複数のプロジェクトを共有しているときは、右上のプロジェクト名のボタンからプロジェクトを切り替えたり、新しいタブで開いたりできます（同じプロジェクトを複数のタブで開いてもかまいません）。ホストがワンタイムパスワードを使っているときは、最初に受け取ったワンタイムパスワードでログインします。

    
ローカルネットワークの外から使うときは、ホストを komenagare --otp --tunnel tailscale（または cloudflare / ngrok）で起動するか、自分で用意した URL を --public-url で渡します。詳しくは README を見てください。

    
ほかの参加者の再生位置・選んでいるコメント・マウスカーソルは、その人の色でシークバー・タイムライン・リスト・プレビューに薄く出ます。右上の「共同編集」を押すと参加者の一覧が開き、表示名の変更や、選んだ人の再生位置とタイムラインの表示を「追いかける」ことができます（自分でシークやスクロールをするとやめます。回線が切れても、同じ人がつなぎ直してくれば追いかけ続けます）。参加者が入ったり抜けたりすると、短く知らせます。

    
再生バーの 📣（ここ見て）を押すと、今の再生位置と選んでいるコメントをほかの参加者に知らせます。受け取った人は「見る」でそこへ移れます。🔗 は今の位置へのリンク（コメントを1件選んでいればそのコメントへのリンク）をコピーします。メッセージで送れば、開いた人がそこへ移ります（動画を開く前なら、開いたときに移ります）。

    
動画は各自が手元のファイルを開くので、ほかの人と動画の長さが違うと知らせます（違う動画だと、コメントの出る場面がずれます）。参加者の一覧にも出ます。

    
ホストが --remote を付けて起動していて、あなたに許可があるときは、右上の「ターミナル」からホストの作業フォルダでコマンド（git status・git push など）を打てます。入力を求めるコマンドは使えません。打ったコマンドはホストに記録されます。

    
同じ人は「タイムマシン」で、git に残っている前のコメントをさかのぼって見られます。右の目盛り（上が古く、一番下が今。日ごとに薄い帯で区切り、1本の長さはそのコミットの変更の多さ）にマウスや指を近づけると、そのあたりの目盛りが拡大鏡のように伸びて日時が出て、押すとそのときのコメントになります（スマホは指でなぞって離す）。目盛りが多いときはスクロールでき、PC はホイール、スマホは素早くスワイプでスクロールし、押して少し止めてからなぞると選びます。そのコミットで追加・変更したコメントは枠で囲い（メニューバーの「変更 n 件」で順に飛べます）、タイムラインでは最近変えたものほど明るく出します。見ている間も再生・タイムライン・書き出しは使えますが、編集はできません。「この時点に復元…」は、今のコメントからそのときのコメントに戻す変更を新しいコミットとして記録します（履歴は消えません）。


    
ファイル形式

    
JSON：{"t": 秒, "cmd": "コマンド", "text": "本文", "id": "UUID"} の配列（comments キー内）。CSV：time,command,text,id の4列。表計算ソフトで数式として動かないよう、= + - @ などで始まるセルは先頭に ' を付けて書き出します（コメナガレで読み込むと元に戻ります）。id は各コメントを見分ける番号で、省略すると読み込み時に新しく付きます。読み込みはニコニコのコメントXML（<chat vpos mail>）やコメントJSONにも対応しています。


    
言語

    
URL に ?lang=en を付けると英語、?lang=ja で日本語になります（メニューバーの「設定」でも変えられます）。選んだ言葉はこのブラウザで覚えます。ホスト（komenagare コマンド）からのメッセージは日本語のままです。
